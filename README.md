# 家計簿アプリ (Kakeibo App)

スマホ・PC両対応の家計簿管理アプリです。日々の収支入力から、カテゴリ別の予算管理、月次サマリーの確認までを1つのアプリで完結できます。

## デモ

🔗 **[デモを試す](https://nori20010213-gif.github.io/kakeibo-app-demo/)**

※本デモはサンプルデータで動作する検証用環境です。実際の家計データとは分離しています。

## 主な機能

- 収支入力(支出・収入の切り替え、カテゴリ選択、金額・メモ・日付・備考の登録)
- カテゴリ別の月次サマリー表示(予算に対する使用率をバーで可視化)
- カテゴリ別予算上限の設定・管理
- PWA対応(ホーム画面に追加してアプリのように利用可能)
- スマホ・タブレット・PCに対応したレスポンシブデザイン

## 技術的な工夫

### 日付のタイムゾーン処理

`Date` オブジェクトの `valueAsDate` はUTC基準で扱われるため、日本時間の早朝(0時〜9時)にアプリを開くと、日付が前日にずれて表示される問題がありました。ローカルの年月日から直接文字列を組み立てることで、この依存関係を回避しています。

同様に、GAS側でも `new Date(y, m-1, d)` がスクリプトのタイムゾーン設定に依存してしまう問題があったため、`Utilities.parseDate` でタイムゾーンを明示指定し、書き込み後の日付ズレを防いでいます。

### 数式インジェクション対策

スプレッドシートのセルは `=` `+` `-` `@` で始まる文字列を数式として実行してしまう仕様があります。外部から送信された文字列をそのままセルに書き込むと、意図しない数式(例: 外部サーバーへのデータ送信を行う数式)を仕込まれる可能性があるため、該当する文字で始まる入力値は先頭にシングルクォートを付与して無害化しています。

### レスポンシブ対応

モバイルではボトムナビゲーションによる画面切り替え、768px以上のタブレット・PC幅では入力フォームとサマリーを2カラムで同時表示する設計にし、デバイスごとに最適なUIを提供しています。

### UIデザイン

数字を毎日見るアプリだからこそ、視認性とレイアウトにこだわりました。オレンジを基調にしたミニマルなカードデザインで、カテゴリ別の予算消化率は色付きバーで直感的に把握できるようにしています。

さらに、Mac起動時にデスクトップへ表示されるウィジェットも自作しました。スピードメーターを模したポルシェ風のUIで、収入・支出・残高をゲージで表示し、起動、スリープ解除のたびに針が0%から100％に振れてから実際の値まで滑らかにスイープするアニメーションを実装しています。単なる数字表示ではなく、見るたびに気分が上がる「毎日開きたくなるデザイン」を意識しました。

## 画面構成

- **収支入力**:カテゴリ選択・金額・メモ・日付・備考を入力して登録
- **サマリー**:今月の収支、カテゴリ別の予算消化率を表示
- **設定**:カテゴリ別の予算上限を設定
- **デスクトップウィジェット**:起動時に収入・支出・残高をスイープアニメーション付きのゲージで表示(Mac版)
